# GPU Hardware & CUDA Software Study Guide

Open [index.html](index.html) in a browser. It is a local, dependency-free study
guide covering course Modules 1–3, NVIDIA CUDA Programming Guide Part 1, and
verified CUDA 13.3 labs.

The runnable programs are in [examples](examples/README.md). On Windows:

```powershell
cd GPU_Study_Guide\examples
Set-ExecutionPolicy -Scope Process Bypass
.\build_and_run.ps1
```

The runner initializes the installed Visual Studio C++ toolchain automatically.
